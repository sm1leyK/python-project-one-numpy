# Project 1 运行说明 / Running Instructions

## 项目简介 / Project Overview

本项目使用 NumPy 复现 OpenCLIP ViT-B/32 的图像编码器前向计算。
This project reproduces the forward pass of the OpenCLIP ViT-B/32 image encoder using NumPy.

项目不进行模型训练，模型参数、图像数据和参考结果由项目附件提供。
No model training is performed. The model parameters, images, and reference data are supplied with the project.

## 环境 / Environment

- Python 3.9 或更高版本 / Python 3.9 or later
- NumPy
- Pillow

在项目目录中安装依赖：
Install the dependencies from the project directory:

本压缩包仅包含提交材料。运行代码时，需要将 image_encoder.py 放回完整的 project1-numpy-student 项目目录中。

```bash
python3 -m pip install -r requirements.txt
```

## 运行分阶段检查 / Run Staged Checks

进入项目目录：
Change to the project directory:

```bash
cd project1-numpy-student
```

推荐按照以下顺序检查：
Run the checks in the following order:

```bash
python3 check.py --stage patches
python3 check.py --stage tokens
python3 check.py --stage block0
python3 check.py --stage last_tokens
python3 check.py --stage output
python3 check.py --stage batch
```

运行全部检查：
Run all checks:

```bash
python3 check.py --stage all
```

完整检查应通过预处理、patch、token、Transformer block、最终输出和 batch 检查。
The complete check should pass preprocessing, patch, token, Transformer block, final-output, and batch checks.

## 生成输出 / Generate Outputs

使用项目内置的十张图像生成输出文件：
Generate output tokens for the ten supplied images:

```bash
python3 run.py --output output_tokens.npz
```

也可以指定其他图像：
Other images can also be supplied:

```bash
python3 run.py --images path/to/a.jpg path/to/b.png --output my_tokens.npz
```

输出文件包含图像 ID 和对应的 512 维图像向量，并按照输入顺序保存。
The output file contains image IDs and the corresponding 512-dimensional image vectors in input order.

## 验证结果 / Verification Result

本次实现中，`python3 check.py --stage all` 已全部通过；`run.py` 生成的输出为 `float32`，形状为 `[10,512]`，每一行的长度约为 1。
In this implementation, `python3 check.py --stage all` passed all stages. The output generated by `run.py` has dtype `float32`, shape `[10,512]`, and approximately unit length for every row.
